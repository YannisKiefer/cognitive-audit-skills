# Report Writer

## Fixed Order

Do NOT open with an academic dump. The order is the product:

1. **HOW YOU ACTUALLY WORK** - one page maximum. The dominant work loop in
   direct concrete language.
2. **THE 10 THINGS YOU MAY NOT REALIZE** - each with finding, why it
   matters, strongest evidence, counterevidence, confidence, what to do
   differently. Surprising + actionable beats flattering.
3. **BELIEF VS BEHAVIOR** table.
4. **DECISION OPERATING SYSTEM** - how I begin, reduce uncertainty, choose,
   react to failure, verify, call something done.
5. **STRENGTH -> SHADOW PAIRS** - evidence-backed only.
6. **RECURRING FAILURE LOOPS** - ranked by expected impact.
7. **WHAT I ACTUALLY LEARN** - fastest areas, gaps, transfer wins.
8. **DELEGATION FRONTIER** - four buckets, task-specific:
   DELEGATE COMPLETELY / DELEGATE + VERIFY / COLLABORATE DEEPLY /
   KEEP HUMAN-LED.
9. **ME x MODEL MATRIX** - which model for which work, from outcomes.
10. **WHERE AI MAKES ME BETTER / WORSE / ONLY FEELS EASIER.**
    The third category exists only if evidence supports it.
11. **HIDDEN BOTTLENECKS** - never assume coding speed is the constraint.
12. **PERSONAL OPERATING MANUAL** - about 10 rules:
    WHEN [observable situation] DO [specific behavior]
    BECAUSE [evidence-backed reason].
13. **EARLY-WARNING SIGNALS** - "if X happened twice, stop and do Y."
14. **THREE CHANGES ONLY** - behavior, evidence, expected benefit,
    difficulty, exact replacement behavior, measurement.
15. **LEARNING ROADMAP** - LEARN DEEPLY / UNDERSTAND ENOUGH TO SUPERVISE /
    SAFE TO OUTSOURCE.
16. **WHAT I CANNOT KNOW FROM THESE DATA** - unsupported conclusions,
    missing data, confounders, selection bias, retrospective limits,
    hypotheses needing prospective tests.

## Success Criterion

The reader should repeatedly think:

> "I didn't realize I did that."

then

> "Now I know exactly what to do differently."

It FAILS if it mainly says: ambitious, curious, moves fast, likes
technology, detail-oriented, communicate clearly, take breaks.

## Discipline

Outcome measures only. State uncertainty on cycle times. No clinical or
personality labels anywhere. Methodology and sources documented separately
from the personal report (see SOURCES.md).

## One-Line Memory

One page of truth before fifty pages of proof.
