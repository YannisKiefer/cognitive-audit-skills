# Audit Router

## The Big Idea

An audit of a person's work behavior is a pipeline, not a vibe read.

Under pressure an analyst doesn't rise to the moment. They fall to their
method. First match wins. One phase per pass.

This is never a personality quiz, therapy, or clinical assessment. No
diagnoses, no IQ, no neurodivergence labels, no MBTI, no astrology
archetypes. The subject is observable work behavior. Nothing else.

## Hard Rules (apply everywhere)

1. Behavior over labels.
2. Never attribute the model's behavior to the human.
3. One anecdote proves nothing. Patterns repeat or they don't exist.
4. Secrets never leave the corpus.
5. Surprising and actionable beats flattering.
6. If the data can't support it, say so in the report's limits section.

## The Ten-Second Version

New corpus: discover sources before claiming anything.
Any interpretation: attribute first, episodes second, messages last.
Every finding: evidence, frequency, counterevidence, confidence, consequence.
Every report: one page of truth before fifty pages of proof.

## One-Line Memory

First match wins. Method over horoscope.
