# Blindspot Miner

## The Search Grid

Generate candidates across ten grids:

1. LONGITUDINAL - visible only across months
2. CROSS-PROJECT - same behavior in unrelated contexts
3. CROSS-MODEL - behavior constant despite different assistants
4. CONTRADICTIONS - stated preference vs measured behavior
5. MIS-CALIBRATIONS - expected vs actual divergence
6. HIDDEN BOTTLENECKS - apparent problem is not where time and rework go
7. UNDERUSED STRENGTHS - good-outcome behaviors applied inconsistently
8. COSTLY DEFAULTS - reasonable sometimes, applied automatically always
9. AI-INDUCED BEHAVIOR - specific assistants improving or degrading process
10. UNBUILT SYSTEMS - lessons corrected manually that never became tooling

Plus two uncomfortable hunts: productive-feeling-but-empty work (outcome
evidence required) and undervalued high-leverage habits.

## The Kill Question

For every candidate ask:

> Would this still be interesting if the subject already knew it?

If no, deprioritize. The report lives or dies on non-obviousness.

## Evidence Standard

Every significant insight carries all fields:

OBSERVATION / EVIDENCE / FREQUENCY / DATE RANGE / PLATFORMS /
REPRESENTATIVE EPISODES / COUNTEREVIDENCE / ALTERNATIVE EXPLANATIONS /
CONFIDENCE / PRACTICAL CONSEQUENCE

Apply the 3x3x3 principle: a finding across 3 independent tasks, 3 months,
3 different contexts beats one vivid anecdote every time.

Confidence ladder: HIGH, MEDIUM, LOW, SPECULATIVE. Never dress LOW up as
fact. Do not cherry-pick dramatic conversations.

## One-Line Memory

If they would nod immediately, it isn't a finding.
